PORTFOLIO - HOW TO EDIT
Files: index.html (page text), style.css (colors/layout), script.js (games, films, animations), images/ (all pictures).
Open index.html in a browser to preview. Upload the whole folder to any static host (Netlify, GitHub Pages, etc.).
Add a game or film: edit the lists G / F in script.js (instructions are in the comments above each list).
Add a picture: put it in images/ and register it in the "I" list at the top of script.js.
Change contact info: edit the Contact section in index.html. Change colors: top of style.css.
Fonts load from Google Fonts, so an internet connection is needed for them.
